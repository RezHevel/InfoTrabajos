Bundled Lucide glyph, stroked with currentColor — use it for every icon instead of hand-rolling SVG.

```jsx
<Icon name="wrench" size={20} />
<Icon name="map-pin" size={16} style={{ color: "var(--text-muted)" }} />
```

50 glyphs ship in `assets/icons/`: trade glyphs (wrench, hammer, hard-hat, paint-roller, brick-wall, zap, shovel, spray-can, sprout, droplets, scissors, truck), UI (search, sliders-horizontal, menu, x, plus, check, chevron-*, arrow-*, eye, pencil, trash, send, camera), and marketplace (star, map-pin, message-square, badge-check, shield-check, clock, calendar, briefcase, user-round, users, bell, phone, trending-up, file-text, layout-dashboard, settings, log-out, heart, circle-check, circle-alert, info).
